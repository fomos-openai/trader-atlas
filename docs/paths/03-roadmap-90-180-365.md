# 90/180/365 天个人路线图

路线图按“可验收产物”管理，不按阅读时长或收益排名管理。若每周可投入时间有限，延长日历，不删减验证步骤。

## 0–90 天：建立研究系统

- 写完个人交易政策、资金分层与香港边界清单。
- 跑通 BTC/ETH 案例；能解释每个输入、滞后、成本和指标。
- 建立 experiment ledger：每次试验都有唯一 ID、假设、参数、数据摘要和结果。
- 交付一份基准回测和一份“为什么可能是错的”反证报告。

**验收**：换一台机器可重现；测试可捕获前视与成本遗漏；没有任何实盘连接。

## 91–180 天：建立本地 Paper 纪律

- 每个新 bar 只处理当时可见数据，生成不可回写的意向订单。
- 连续记录理论仓位、模拟成交、现金、费用、偏差和异常。
- 完成至少一次数据中断演练和一次恢复演练。
- 按月做收益来源、风险暴露与规则偏离归因。

**验收**：重启不重复记账；数据过期会 fail closed；未处理异常不会自动越过。

## 181–365 天：形成 OPC 操作系统

- 固化周/月/季度复盘，统计研究吞吐、失败率和规则例外，而非只看收益。
- 至少退役一个没有证据优势的想法，证明停止机制有效。
- 更新税务/监管资料和平台尽调；保留可审计记录。
- 写出下一年度路线：继续单策略深挖，还是仅在证据支持时扩展第二策略。

**验收**：知识、代码、数据和决策记录互相可追溯；任何外部审阅者能区分研究结论、paper 结果与未经验证的推测。
