# 成长路径

路径页只规定学习与交付顺序，不复制知识正文。对已有十年技术开发管理经验、三年数字资产手工交易及基金/ETF 经验的人，优势是系统建设与市场直觉；主要缺口通常是可证伪研究、风险预算、样本外验证和持续执行纪律。

- [最短成长路径](01-fast-track.md)：先构建一个最小可行研究系统，而不是同时研究多个策略。
- [阶段门](02-stage-gates.md)：每阶段需要哪些证据，以及失败时如何退出。
- [个人路线图](03-roadmap-90-180-365.md)：把 90/180/365 天目标写成可验收产物。

建议一次只推进一个主案例。并行阅读可以，策略开发不要并行扩散。
