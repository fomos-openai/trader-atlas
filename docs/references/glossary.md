# 术语表

- **Backtest / 回测**：按历史数据和明确事件顺序模拟规则；不是未来预测。
- **Bar / K 线**：某时间区间的 OHLCV 汇总；必须说明时间戳代表开盘还是收盘。
- **Capacity / 容量**：在成本和冲击不使策略失效前可承载的规模。
- **CIS / Collective Investment Scheme / 集体投资计划**：香港法律定义需按实际安排判断；涉及汇集或共同管理他人资产时应咨询专业人士。
- **Drawdown / 回撤**：权益从历史峰值下跌的幅度及路径。
- **Edge / 优势**：可证伪、成本后仍可能存在的收益或风险改善机制，不是经验标签。
- **Guardrail / 护栏**：限制系统正常运行范围的硬条件。
- **Kill switch / 停止开关**：信息不可信或风险越界时停止新增动作的机制。
- **Look-ahead bias / 前视偏差**：在历史决策中使用当时尚不可见的信息。
- **Momentum / 动量**：过去价格变化方向或相对强弱的量化描述。
- **OPC / One-Person Company**：由一人承担研究、风险、工程、运营与治理的经营形态。
- **Out-of-sample / 样本外**：未用于选择规则或参数的数据；反复查看后不再真正样本外。
- **Paper trading / 纸面交易**：按真实时间生成和记录模拟意向/成交。本仓库仅生成本地 intentions，不连接外部账户。
- **Point-in-time data / 时点数据**：保留历史时刻真实可见状态的数据。
- **PBO / Probability of Backtest Overfitting**：评估从多个回测中挑选胜者导致过拟合概率的框架。
- **Regime / 市场状态**：具有不同方向、波动或流动性特征的时期；不得事后无限切分。
- **Sharpe ratio**：单位波动的平均超额收益估计；受样本、非正态、序列相关和选择偏差影响。
- **Slippage / 滑点**：参考价格与模拟/实际成交价格之间的差异。
- **VATP / Virtual Asset Trading Platform**：虚拟资产交易平台；在香港的牌照状态以 SFC 最新名单为准。
- **Walk-forward**：只用过去窗口决定下一时期规则的顺序验证方式。
- **Whipsaw / 反复止损**：横盘或快速反转中信号频繁切换并累积损失与成本。
