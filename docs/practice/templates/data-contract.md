# 数据契约模板

- Dataset ID / 版本 / owner：
- 来源、许可、下载方式与日期：
- 资产、venue、报价货币、频率、时区：
- timestamp 语义与 bar 边界：
- 字段、类型、单位和 point-in-time 可用时刻：
- 唯一键、排序与日历：
- 缺失、重复、异常、修订和停更规则：
- 质量门槛与 fail-closed 条件：
- 原始文件 SHA-256、转换 commit 与输出哈希：
- 保存、再分发和敏感信息限制：
- 替代源 / 退役条件 / 下次复核日：
