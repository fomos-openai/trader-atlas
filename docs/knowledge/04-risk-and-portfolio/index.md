# 风险与组合

风险管理不是让波动消失，而是保证错误、极端行情和操作失败不会越过个人承受能力。顺序是：风险偏好 → 风险预算 → 仓位 → 压力测试 → 监控 → 停止。

本域的产物不是一个“最优仓位”，而是一份可执行风险政策：可失去多少、如何[构建组合](portfolio-and-volatility-targeting.md)、单一资产/平台上限、何时减仓、何时转现金、何时停止研究或 paper。分别使用[回撤与压力测试](drawdown-stress-tail-and-regime-risk.md)和[流动性/对手方检查](liquidity-capacity-and-counterparty.md)，避免把不同风险压成一个波动数字。
