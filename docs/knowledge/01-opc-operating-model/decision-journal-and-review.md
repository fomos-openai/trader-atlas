# 决策日志与复盘

收益是滞后且噪声很大的结果指标。OPC 需要同时管理过程质量、风险暴露和经营连续性。

## 指标分层

- **过程指标**：有明确假设的实验比例、可重现运行比例、未解释数据异常数、规则例外数。
- **风险指标**：当前与峰值回撤、预期短缺的情景估计、单一平台/资产集中度、数据陈旧度。
- **结果指标**：净收益、波动率、最大回撤、Calmar/Sharpe 等；必须与现金基准和被动持有基准比较。
- **经营指标**：资金跑道月数、固定成本、待处理事件、备份恢复测试日期。

## 最小记录集

每次研究运行保存：唯一 run ID、问题与假设、代码 commit、环境锁文件、配置、输入数据指纹与时间范围、输出指标、图表、已知限制和结论。每次 paper 决策保存：决策时刻、当时可见数据、目标仓位、模拟成交假设、费用、拒绝/暂停原因。

## 记录纪律

- 原始输入只读，派生数据可重建。
- 失败结果不可删除；新实验用新 ID。
- 结论与证据路径双向链接。
- 每月生成归档包并做恢复抽查；备份存在不等于可恢复。

真正的目标是让三个月后的自己能够回答“当时为什么做这个决定”，而不是只看到一条权益曲线。

决策日志必须区分事实、解释、决定和后验结果。先写当时可见信息与备选方案，再写决定；结果发生后另开复盘段，禁止回写原始判断。季度复盘统计规则例外、重复错误和被及时停止的项目，用这些过程证据改进系统。
