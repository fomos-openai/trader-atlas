# 职业转型与个人优势

从技术管理转向独立交易，最可迁移的能力是系统分解、版本控制、事故复盘和长期交付；最不可直接迁移的是“复杂系统等于更强优势”的直觉。市场研究应优先选择能被简洁规则解释、数据可获得、交易频率低且失败可识别的问题。

## 转型门槛

- 时间：能连续维持研究、测试、paper 与复盘，而非只在行情活跃时投入。
- 证据：至少一个研究项目被独立复现，且失败实验同样留档。
- 风险：预先定义最大组合损失、单一平台暴露和暂停条件。
- 运营：关键数据、代码和账本有恢复演练；本人离线时系统不会产生未授权行为。

## 个人优势假设

把“优势（edge）”写成可证伪句：例如“低频规则与严格执行能减少手工追涨和频繁切换造成的行为误差”。优势不是“懂技术”或“交易多年”；它必须对应可测量机制、适用边界和失效信号。

## 差距清单

工程经验不能替代金融统计与市场微观结构；手工交易经验也不能直接当作量化样本。对每项能力标记 `已有证据 / 需要练习 / 需要外部复核`，优先补齐会导致不可逆损失的缺口：风险预算、数据时点、回测偏差、香港活动边界和恢复能力。
