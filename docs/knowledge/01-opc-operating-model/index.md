# OPC 经营模型

专业独立交易员首先是一个受资本、时间和认知约束的经营系统，不是每天必须交易的职位。OPC 的优势是决策链短和工程能力可复用；脆弱点是缺少独立复核、收入集中、运营单点故障，以及容易把个人需要当成市场机会。

本域交付三件事：

- [职业转型与个人优势](career-transition-and-edge.md)：识别可迁移能力、差距与可证伪优势。
- [资金跑道与个人交易政策](capital-runway-and-trading-policy.md)：隔离生活、经营与风险资本。
- [决策日志与复盘](decision-journal-and-review.md)：把研究质量与经营健康转成证据。
- [香港监管、税务与经营边界](hong-kong-regulatory-and-tax-boundaries.md)：识别必须寻求专业意见的触发点。

完成本域后，应能用一页纸回答：可投入的时间与风险资本是多少、什么活动明确不做、何种损失会触发暂停、哪些记录必须保存、何时需要法律或税务意见。
