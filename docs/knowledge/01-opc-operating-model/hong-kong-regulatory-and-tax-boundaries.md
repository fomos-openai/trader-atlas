# 香港监管、税务与经营边界

本页是截至 `as_of` 的研究清单，不是法律或税务意见。数字资产分类、服务方式和个人活动事实都可能改变结论；到 `review_due` 或业务模式变化时，以香港官方材料和专业意见重新核验。

## 先区分四种活动

1. **仅以自有资金进行现货研究/交易**：不要由此推导“永远无需牌照”。是否构成业务或受规管活动取决于实际行为、资产性质、推广对象和服务安排。
2. **为他人管理、汇集或决定资金**：可能触及资产管理、集体投资计划（CIS）或其他受规管活动；在提供服务或收取报酬前应取得香港法律意见。
3. **经营或积极推广中央化虚拟资产交易平台**：SFC 明确说明，在香港经营或向香港投资者积极推广的平台须受相应发牌制度规管。平台申请中不等于已持牌，应查询[SFC 平台名单](https://www.sfc.hk/en/Welcome-to-the-Fintech-Contact-Point/Virtual-assets/Virtual-asset-trading-platforms-operators/Lists-of-virtual-asset-trading-platforms)。
4. **证券型代币、衍生品、投顾、信号销售或公开募资**：不能沿用“普通现货”假设；应逐项进行产品分类与牌照分析。

## 平台与资产边界

- 只使用最新官方名单核验持牌状态；SFC 明确提醒，申请人未必最终获牌，持牌也不等于对平台表现或信用作保证。
- 记录平台法律实体、牌照编号、资产托管方式、客户资产隔离、提款条件、争议法域和状态核验日期。
- “存款”“双币”“收益”“staking”等名称不等于银行存款。SFC 提醒某些回报安排可能损失全部本金，部分安排还可能构成 CIS。

## 税务边界

香港税务局 [DIPN 39](https://www.ird.gov.hk/eng/pdf/dipn39.pdf) 对数字资产与利得税处理给出原则。不能把“香港通常不征资本增值税”简化为“数字资产收益永不纳税”：若活动按事实构成经营交易业务，相关利润可能落入利得税分析；资产取得目的、交易频率、持有期、组织方式、资金与记录都会影响判断。

最小记录包括每笔取得与处置时间、数量、港币计值方法、费用、钱包/平台、转账证据、业务目的和年末余额。涉及频繁系统化交易、公司架构、他人资金、跨境实体或不确定来源地时，向香港税务专业人士确认。

## 必须暂停并咨询的触发器

- 接受他人资金、分成、订阅费或信号费；
- 对公众宣传具体回报或共同投资安排；
- 交易可能属于证券、期货、结构性产品或衍生品的数字资产；
- 设立公司、雇员或跨境服务器后仍沿用个人税务假设；
- 无法从官方名单确认平台状态，或平台提款/托管条款发生重大变化。
