# 市场与策略

数字资产 24/7 交易、跨平台定价、托管与操作风险显著，策略收益不能脱离平台、成本和资产可取回性讨论。首版只研究 BTC/ETH 现货 long/cash；衍生品、收益产品和传统市场作为后续扩展，不进入首个 runnable case。

学习顺序是[现货市场结构](crypto-spot-market-structure.md)、[托管与稳定币风险](custody-counterparty-and-stablecoin-risk.md)、[交易成本与执行](transaction-costs-liquidity-and-execution.md)、[工具与衍生品边界](instruments-derivatives-and-dual-investment.md)、[策略选择](strategy-families-and-selection.md)，最后再评估[传统市场扩展](traditional-market-expansion.md)。

本域完成标准是写出一张策略选择卡：收益机制、依赖数据、主要成本、尾部风险、可承载资金、停止条件和为何当前不选其他策略。
