# OPC 专业独立交易员知识树

知识树按决策依赖而非学科百科组织：先确定个人经营与资本边界，再选择市场和策略；随后建立数据证据、风险组合、工程流水线和持续运行纪律。六域必须闭环，工程能力不能代替统计证据，历史交易经验也不能代替风险预算。

1. [OPC 经营模型](01-opc-operating-model/index.md)：职业转型、资金跑道、决策记录与香港边界。
2. [市场与策略](02-markets-and-strategies/index.md)：数字资产现货优先，理解结构、成本、托管和策略选择。
3. [数据与研究](03-data-and-research/index.md)：用数据契约、实验账本、偏差控制和样本外验证建立证据。
4. [风险与组合](04-risk-and-portfolio/index.md)：把风险偏好转成仓位、压力、容量和停止规则。
5. [工程与工具](05-engineering-and-tools/index.md)：让研究与本地 paper 可复现、可观测、可恢复。
6. [研究运行纪律](06-production-discipline/index.md)：用阶段门、监控、事件管理和评分卡维持长期质量。

阅读不等于达标。每一域至少产出一份可审查制品，并在[实践区](../practice/index.md)用 playbook 和模板留下证据；首次贯通使用 [BTC/ETH 现货趋势轮动案例](../case/btc-eth-spot-trend/index.md)，范围止于研究和本地 paper。
