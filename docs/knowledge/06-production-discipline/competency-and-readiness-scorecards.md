# 能力与就绪度评分卡

每项按 `0 未建立 / 1 有文档 / 2 有可复现证据 / 3 经异常或独立复核验证` 评分：市场机制、统计与时序、数据契约、回测可信度、风险预算、Python 工程、paper 账本、事件恢复、香港边界、复盘纪律。

总分不覆盖红线：香港边界、前视偏差、账本不平、风险预算和恢复能力任一低于 2，都不能进入 paper。评分证据必须链接到具体文档、测试或 run manifest。

路线图按最低项安排学习，不追求每项都做成专家。技术背景者通常工程分较高，但统计验证与模型风险仍需独立证据；交易经验丰富也不能替代记录与可复现。
