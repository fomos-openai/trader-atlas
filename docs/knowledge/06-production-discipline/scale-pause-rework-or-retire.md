# 扩展、暂停、重研或退役

当前“扩展”只指扩大研究样本、paper 观察期或验证范围，不指增加真实资金。季度审查只允许四个结论：继续当前范围、在限定条件下扩展、暂停并重研、退役。

扩展需要新增证据而不是短期盈利：数据稳定、冻结规则在样本外和 paper 保持一致、异常可恢复、容量/成本边界可解释。暂停用于信息暂时不可信；重研会产生新策略版本；退役用于机制、数据、成本、法域或运营能力不再支持。

每个决定记录证据、反对意见、限制和下次复核。若无法区分“暂时回撤”与“模型失效”，默认降级或暂停，而不是增加复杂度。
