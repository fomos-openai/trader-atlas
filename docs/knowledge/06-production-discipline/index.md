# 研究运行纪律

本域借用 production discipline，但范围严格止于本地 paper。目标是在没有真实资金压力时就暴露数据、时钟、状态、规则漂移和复盘问题。

完成本域后，应有：研究到 paper 的审批记录、每日逐 bar 账本、监控与归因、事件与变更记录、定期复盘，以及可执行的退役决定。连续运行天数不是成功标准；能在错误条件下正确停止才是。
